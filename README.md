# Помощник для морского боя

Откройте `index.html` в браузере. Установка и сборка не нужны.

- Поле 10×10, классический флот: 4, 3, 3, 2, 2, 2, 1, 1, 1, 1.
- Нажмите клетку и выберите «Промах», «Попал» или «Убил».
- Отмечайте каждую раненую палубу. «Убил» на последней палубе объединяет соседние попадания в корабль и закрывает клетки вокруг, включая диагонали.
- Сначала жёлтым появляется быстрая предварительная подсказка. Затем фоновый расчёт выбирает цель по ожидаемому числу выстрелов до победы и показывает приблизительный шанс попадания.
- «Отменить» возвращает предыдущий ход вместе с автоматически закрытыми клетками.
- Игра сохраняется локально в браузере. При запрете локального хранилища можно играть без сохранения.

Интерфейс адаптируется к телефону и поддерживает управление с клавиатуры. Внешний шрифт необязателен: без сети используется системный.

### Как рассчитывается следующий ход

1. По всем попаданиям, промахам и потопленным кораблям строятся **полные допустимые расстановки** оставшегося флота. Учитываются количество и длины кораблей, запрет соприкосновения, в том числе по диагонали. Корабль, все палубы которого поражены, должен быть отмечен как потопленный.
2. Четыре цепочки случайных перестановок кораблей собирают 512 расстановок. Одновременно переставляются один или два корабля. Целевое распределение — равномерное по допустимым расстановкам; конечная выборка приближённая, может иметь смещение и корреляции. Равномерное размещение не моделирует привычки конкретного человека.
3. Для каждой клетки, занятой хотя бы в одной выборочной расстановке, моделируются партии до потопления всего флота. Эквивалентные клетки объединяются по поворотам и отражениям, сохраняющим все отметки поля: это ускоряет начало игры. Продолжение использует быструю стратегию допустимых размещений и добивания. **Выбор следующих выстрелов видит только наблюдаемое поле**, скрытая расстановка используется исключительно для ответа на выстрел.
4. Сравнение идёт этапами: 8, 24, 64 и 160 партий на кандидата. После каждого этапа остаётся примерно треть кандидатов; базовый ход сохраняется для сравнения. Все кандидаты получают одинаковые расстановки и начальные состояния генератора случайных чисел. Незавершённый этап отбрасывается, чтобы не сравнивать оценки на разном количестве партий.
5. Выбирается ход с наименьшим средним числом выстрелов среди кандидатов, достаточно устойчиво обгоняющих базовую стратегию. Если такого нет, остаётся базовый ход. Для защиты от шума среднее попарное улучшение должно превышать две стандартные ошибки различий; это эвристический порог, не гарантия статистической значимости.

Оценка оставшихся выстрелов включает следующий выстрел. Это одноступенчатый Monte Carlo rollout с эвристическим продолжением, **не полный поиск оптимальной стратегии**. Ни минимальное число ходов в конкретной партии, ни превосходство над базовой стратегией для любого противника не гарантируются. Отбор кандидатов, конечная выборка и качество стратегии продолжения ограничивают точность. Пересчёт после каждого реального выстрела может изменить стратегию относительно смоделированного продолжения.

Расчёт имеет бюджет времени около 12 секунд; при его исчерпании используются результаты последнего полностью завершённого этапа или предварительная подсказка. Web Worker не блокирует интерфейс. Если браузер запрещает Worker, используется расчёт с периодическими уступками главному потоку. Новый ход, отмена и новая игра отменяют устаревший расчёт. Повторный расчёт одинаковой позиции воспроизводим при одинаковом количестве завершённых этапов.

Проверка игровой логики, планировщика и связи интерфейса с фоновым расчётом: `node --test engine.test.js planner.test.js app.test.js` (Node.js 18+). Тесты интерфейса используют подмены DOM и Worker и не заменяют визуальную проверку в браузере.
