# Помощник для морского боя

Откройте `index.html` в браузере. Установка и сборка не нужны.

- Поле 10×10, классический флот: 4, 3, 3, 2, 2, 2, 1, 1, 1, 1.
- Нажмите клетку и выберите «Промах», «Попал» или «Убил».
- Отмечайте каждую раненую палубу. «Убил» на последней палубе объединяет соседние попадания в корабль и закрывает клетки вокруг, включая диагонали.
- Сначала жёлтым появляется быстрая предварительная подсказка. Затем фоновый расчёт уточняет цель и шанс попадания. В небольших концовках он выбирает ход по ожидаемому числу выстрелов до победы.
- «Отменить» возвращает предыдущий ход вместе с автоматически закрытыми клетками.
- Игра сохраняется локально в браузере. При запрете локального хранилища можно играть без сохранения.

Интерфейс адаптируется к телефону и поддерживает управление с клавиатуры. Внешний шрифт необязателен: без сети используется системный.

### Как рассчитывается следующий ход

1. По всем попаданиям, промахам и потопленным кораблям строятся **полные допустимые расстановки** оставшегося флота. Учитываются количество и длины кораблей, запрет соприкосновения, в том числе по диагонали. Корабль, все палубы которого поражены, должен быть отмечен как потопленный.
2. Когда осталось не более трёх кораблей и 12 неизвестных клеток, алгоритм пытается решить конец игры точно. Он перечисляет все допустимые расстановки без дублирования одинаковых кораблей и перебирает продолжения с ответами «Промах», «Попал» и «Убил». Выбирается ход с минимальным средним числом выстрелов до потопления всего флота. Предполагается равновероятность допустимых расстановок. Если есть гарантированные попадания, их можно сделать первыми без увеличения оптимального числа выстрелов.
3. На точный поиск отводится до 1,5 секунды и 50 000 состояний. Если он не завершён или поле слишком велико, четыре цепочки случайных перестановок кораблей собирают 512 расстановок. Одновременно переставляются один или два корабля. Целевое распределение — равномерное по допустимым расстановкам; конечная выборка приближённая, может иметь смещение и корреляции. Для каждой клетки считается доля расстановок с кораблём, усреднённая по поворотам и отражениям, сохраняющим отметки поля.
4. В точном конце игры подсвечиваются равноценные по ожидаемому числу выстрелов ходы; их шансы попадания могут различаться. В остальных случаях выбираются клетки с максимальным расчётным шансом попадания. Предварительная подсказка добивает раненые корабли; основной расчёт не навязывает отдельный приоритет добивания.

Точная оптимальность относится только к полностью решённой концовке и выбранной модели равновероятных расстановок. Привычки конкретного человека она не моделирует. Максимальный шанс попадания вне точной концовки не гарантирует минимального числа ходов до победы; среднее 40–42 выстрела не обещается.

Расчёт имеет бюджет времени около 12 секунд; если выборка не завершена, остаётся предварительная подсказка по допустимым положениям отдельных кораблей. Web Worker не блокирует интерфейс. Если браузер запрещает Worker, используется расчёт с периодическими уступками главному потоку. Новый ход, отмена и новая игра отменяют устаревший расчёт.

Проверка игровой логики, планировщика и связи интерфейса с фоновым расчётом: `node --test engine.test.js planner.test.js app.test.js` (Node.js 18+). Тесты интерфейса используют подмены DOM и Worker и не заменяют визуальную проверку в браузере.

### Сравнение стратегий

`node benchmark.js 200 512 917431` сравнивает прежний выбор по вероятности (`baseline`) и алгоритм с точной концовкой (`improved`) на одних и тех же 200 расстановках, с 512 образцами на ход и фиксированным seed. Генератор последовательно ставит случайные допустимые корабли; это синтетическое распределение, не равномерная выборка всех флотов и не модель игры человека. Алгоритм получает только наблюдаемое поле; скрытая расстановка используется исключительно для ответа на выстрел.

Вывод включает среднее число выстрелов, медиану, 90-й процентиль, парную разницу, её стандартную ошибку, время расчёта и число ходов с точным решением. При ограничениях времени результат может зависеть от скорости устройства. Отдельный тест проверяет полные партии на всех 28 допустимых расстановках небольшой концовки: точная стратегия требует в сумме 161 выстрел, выбор по точному шансу попадания — 162.

Контрольный прогон на 200 новых расстановках (seed `917431`): `baseline` — 54,985 выстрела, `improved` — 55,170. Парная разница +0,185 при стандартной ошибке 0,260: улучшение среднего результата полной партии не подтверждено. Точный поиск сработал на 1183 ходах; незавершённых общих расчётов не было. Результаты каждой партии сохранены в `benchmark-results.jsonl`. Это локальное улучшение способа решения концовок, а не подтверждение ускорения всей игры.

Дополнительная [проверка четырёх гипотез](experiments/README.md) включала подбор веса смешанной карты и бонус за информацию. Лучший предварительный вариант, смесь 50/50, не подтвердил преимущество на 600 новых случайных полях и ухудшил результат на 200 полях с кораблями у краёв. Экспериментальные варианты сохранены для воспроизведения, но по умолчанию выключены.
