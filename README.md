# Помощник для морского боя

Откройте `index.html` в браузере. Установка и сборка не нужны.

- Поле 10×10, классический флот: 4, 3, 3, 2, 2, 2, 1, 1, 1, 1.
- Нажмите клетку и выберите «Промах», «Попал» или «Убил».
- Отмечайте каждую раненую палубу. «Убил» на последней палубе объединяет соседние попадания в корабль и закрывает клетки вокруг, включая диагонали.
- Сначала жёлтым появляется быстрая предварительная подсказка. Затем фоновый расчёт выбирает цель по максимальному расчётному шансу попадания и показывает приблизительный шанс попадания.
- «Отменить» возвращает предыдущий ход вместе с автоматически закрытыми клетками.
- Игра сохраняется локально в браузере. При запрете локального хранилища можно играть без сохранения.

Интерфейс адаптируется к телефону и поддерживает управление с клавиатуры. Внешний шрифт необязателен: без сети используется системный.

### Как рассчитывается следующий ход

1. По всем попаданиям, промахам и потопленным кораблям строятся **полные допустимые расстановки** оставшегося флота. Учитываются количество и длины кораблей, запрет соприкосновения, в том числе по диагонали. Корабль, все палубы которого поражены, должен быть отмечен как потопленный.
2. Четыре цепочки случайных перестановок кораблей собирают 512 расстановок. Одновременно переставляются один или два корабля. Целевое распределение — равномерное по допустимым расстановкам; конечная выборка приближённая, может иметь смещение и корреляции. Равномерное размещение не моделирует привычки конкретного человека.
3. Для каждой неизвестной клетки считается доля выборочных расстановок, в которых она занята кораблём. Оценки усредняются по поворотам и отражениям, сохраняющим все отметки поля.
4. Подсвечиваются все клетки с максимальной вероятностью попадания. Приоритет добивания отдельно не навязывается: выбор определяется вероятностью. Показанный процент округлён, а сравнение использует полную точность.

Продолжения партий не моделируются. Вероятности приблизительные и зависят от конечной выборки расстановок; максимальный шанс попадания следующим выстрелом не гарантирует минимального числа ходов до победы.

Расчёт имеет бюджет времени около 12 секунд; если выборка не завершена, остаётся предварительная подсказка по допустимым положениям отдельных кораблей. Web Worker не блокирует интерфейс. Если браузер запрещает Worker, используется расчёт с периодическими уступками главному потоку. Новый ход, отмена и новая игра отменяют устаревший расчёт.

Проверка игровой логики, планировщика и связи интерфейса с фоновым расчётом: `node --test engine.test.js planner.test.js app.test.js` (Node.js 18+). Тесты интерфейса используют подмены DOM и Worker и не заменяют визуальную проверку в браузере.
